## 前言

這篇官方文件的核心其實是在教你：

> **不要把 Claude Code 當聊天機器人，而是把它當成「可以自主工作的 AI 工程師」。**

Anthropic 強調，Claude Code 的強項不是「回答問題」，而是：

- 讀整個 codebase
- 自己探索架構
- 執行 terminal 指令
- 修改多個檔案
- 跑測試
- 自主完成任務

但要發揮效果，關鍵在於「上下文管理（context management）」與「工作流程設計」。

---

## 1. Context window 很珍貴（最重要）

這是全文最核心概念。

Claude Code 的所有能力都建立在：

- 對話歷史
- 讀過的檔案
- command output
- 修改紀錄

這些都會塞進 context window。

問題是：

> context 越大，品質越差。

所以官方一直強調：

- 避免無意義長對話
- 適時 `/clear`
- 使用 `/compact`
- 把長期知識寫進 `CLAUDE.md`

而不是一直聊天。

---

## 2. `CLAUDE.md` 是核心武器

官方非常推這個。

你應該把：

- 專案架構
- coding style
- workflow
- 常見 command
- lint/test 規則
- PR 規範
- 禁止事項

寫進 `CLAUDE.md`。

這樣 Claude 每次啟動都能知道專案規則。等於：

> 把團隊知識「永久灌進 AI」。

而不是每次重講一次。

---

## 3. 先規劃，再動手

官方建議 workflow：

### ❌ 不好的方式

「幫我直接改」

因為 AI 可能直接亂改。

### ✅ 好的方式

先：

- 分析問題
- 提出 plan
- 說明修改策略

確認後再實作。也就是：

> Plan → Review → Execute

這樣錯誤率低很多。

---

## 4. 小步驟 + 持續測試

Anthropic 很強調：

- 小修改
- 立即測試
- 頻繁 commit

因為 agent 很容易：

- 一次改太多
- 造成 hidden regression
- 自信但錯誤

所以推薦：

- TDD
- lint immediately
- run tests often

不要讓 AI 一口氣改整個專案。

---

## 5. Claude 最擅長「探索型任務」

官方提到 Claude Code 特別適合：

- unfamiliar codebase
- tracing architecture
- large refactor
- finding root cause
- migration
- debugging

因為它可以：

- 搜尋整個 repo
- 建立 mental model
- 自主推理

而不是只做 autocomplete。

---

## 6. 要把它當「Agent」不是 Copilot

這是觀念差異。

**Copilot**：

> 你寫 code，它補 code。

**Claude Code**：

> 你描述目標，它自己想辦法完成。

例如：

> 「找出為什麼 staging API timeout，修掉並補測試」

Claude 會：

- trace request flow
- 看 logs
- 搜 config
- 改 code
- run tests

這是 agentic workflow。

---

## 7. Parallel sessions 很強

進階使用者會：

- 開多個 terminal
- 每個 Claude 處理不同子任務

例如：

- **Terminal A**：backend API
- **Terminal B**：frontend UI
- **Terminal C**：test coverage

這樣效率很高。

---

## 8. 工具鏈比 prompt 更重要

這篇其實一直在傳達：

> Claude Code 的威力不是 prompt engineering。

而是：

- shell tools
- git
- test system
- lint
- `CLAUDE.md`
- hooks
- permissions
- workflow discipline

這些組合起來。

---

## 9. 「證據」比 AI 自信重要

很多社群延伸文章都強調，不要相信：

> "This should work"

而是要求：

- build result
- test output
- screenshot
- actual logs

因為 AI 很容易「看起來有信心」。

---

## 總結

這篇最佳實踐其實是在說：

> 「如何把 Claude Code 從聊天 AI，變成真正能協作開發的大型 agent 系統。」

核心能力是：

1. Context management
2. Persistent project knowledge (`CLAUDE.md`)
3. Planning before coding
4. Incremental verified changes
5. Agent workflow instead of autocomplete mindset
