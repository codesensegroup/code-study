## 學習目標

> 把 Claude Code 從「聊天機器人」升級為「能自主完成任務的 AI 工程師」：掌握 context 管理、CLAUDE.md 專案知識沉澱、Plan→Review→Execute 工作流，以及小步驟驗證、Agent 思維、平行工作等實戰技巧。

## 核心訊息

這篇官方最佳實踐其實只在強調一件事：

> **不要把 Claude Code 當聊天機器人，而是把它當成「可以自主工作的 AI 工程師」。**

Claude Code 的強項不是回答問題，而是：

- 讀整個 codebase
- 自己探索架構
- 執行 terminal 指令
- 修改多個檔案
- 跑測試
- 自主完成任務

但要發揮效果，關鍵在於 **上下文管理（context management）** 與 **工作流程設計**。

## 九個重點速覽

1. **Context window 很珍貴** — 越大越差，要主動用 `/clear`、`/compact` 管理
2. **`CLAUDE.md` 是核心武器** — 把專案知識永久灌進 AI
3. **先規劃，再動手** — Plan → Review → Execute，不要直接「幫我改」
4. **小步驟 + 持續測試** — TDD、頻繁 commit、立即 lint
5. **Claude 最擅長探索型任務** — refactor、debug、migration、trace architecture
6. **要把它當 Agent，不是 Copilot** — 描述目標，讓它自己想辦法完成
7. **Parallel sessions 很強** — 多 terminal 分工，效率倍增
8. **工具鏈比 prompt 更重要** — shell / git / test / lint / hooks 組合才是威力
9. **「證據」比 AI 自信重要** — 不要相信「This should work」，要看實際輸出

## 建議閱讀順序

1. 先建立心態：第 1、6 點（context 概念 + Agent 思維）
2. 再學工具：第 2、8 點（CLAUDE.md + 工具鏈）
3. 套用工作流：第 3、4、9 點（Plan→Execute、小步驟、看證據）
4. 進階使用：第 5、7 點（探索型任務、平行工作）

## 總結

> 「如何把 Claude Code 從聊天 AI，變成真正能協作開發的大型 agent 系統。」

核心能力：

1. Context management
2. Persistent project knowledge（`CLAUDE.md`）
3. Planning before coding
4. Incremental verified changes
5. Agent workflow instead of autocomplete mindset
