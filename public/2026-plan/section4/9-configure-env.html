= 配置好的 Agent

env × discipline

未配置 vs 配置完整環境

❌ 開箱即用

「就一個對話視窗」

  • • 每次重貼一遍專案規則
  • • 每個動作都要點確認
  • • 不知道 gh / aws CLI 可以用
  • • Lint / test 全靠手動跑
  • • 同樣的 review 重做 N 次

✅ 配置完整

「環境替你做事」

  • • CLAUDE.md 規則永久生效
  • • Auto mode 自動審核命令
  • • CLI tools / MCP 整合外部系統
  • • Hook 自動 lint / test / format
  • • Subagent 做 review 不污染主對話

🎬 情境範例

任務：在電商加「使用者追蹤功能」（新 API + UI + 測試 + 部署）

❌ 沒配置環境

把一切塞進巨型 prompt

$ 加 follow 功能，要：

- 用 TypeScript，禁止 any

- 命名要 camelCase

- 寫完跑 npm test

- 用 conventional commit

- 不要動 src/legacy

- 不要碰 .env

- 加完要 lint

- 加 unit test 跟 e2e test

- PR 不要超過 300 行

... (再 50 條)

⚠️ AI 寫到後面忘記前面規則

⚠️ 你下次又要重貼一次

⚠️ 新人加入要學「咒語」

✅ 配置完整

短 prompt + 環境自動補位

$ 加 follow 功能
