重點 #6 · 心態

Agent ≠ Copilot

同一個任務、兩種思維。差別不在 AI 能不能，而是你怎麼用它。

同一個任務：

「找出為什麼 staging API timeout，修掉並補測試」

💡

Copilot 思維

你寫 code，它補 code。逐行 autocomplete。

// api.ts

async function callBackend() {

const res = await fetch(url);

return res.json(); // ← AI 補這行

}

— 然後呢？

你還是要自己 trace、看 log、改 config、寫測試。

✓ 補半行 code

✗ 不知道為什麼 timeout

✗ 不會自己跑測試

✗ 不會去看 staging log

🤖

Agent 思維

你描述目標，它自己想辦法完成。

$ 找出 staging API timeout 原因並修復

→ 🔍 grep "timeout" src/

→ 📖 讀 api.ts、config.ts、middleware/

→ 📊 看 logs/staging.log 最近 100 行

→ 💡 發現 DB pool size 設成 5，staging 流量打爆

→ ✏️ 改 config + 補 retry + 寫 integration test

→ ✅ test pass，回報結果

✓ 自主探索 codebase

✓ 跨檔案推理

✓ 看 log、定位 root cause

✓ 改 code + 寫測試 + 驗證

心法

❌ Copilot 用法

「幫我補這行」「下個 token 是什麼」「這個 syntax 怎麼寫」

✅ Agent 用法

「找出為什麼 X 壞了並修掉」「重構這個模組」「migrate 到 v2 API」

差別不是 AI 能不能 — 是你給它的目標夠不夠大。
