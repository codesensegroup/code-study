📂 範例：一個小型 Nuxt 3 電商專案的 CLAUDE.md

~/my-shop / CLAUDE.md

# 專案架構

- Nuxt 3 + Pinia + Tailwind

- API: /server/api/ · UI: /pages/、/components/

...

# Coding Style

- Composition API + <script setup>，禁止 Options API

- 元件用 PascalCase，composable 用 useXxx()

...

# 常用指令

- pnpm dev · pnpm test · pnpm lint

- ⚠️ 不要用 npm / yarn，pnpm only

...

# Lint / Test 規則

- 提交前一定要過 vitest + eslint

- 新增 API 必須有對應 test

...

# PR 規範

- Conventional Commits：feat: / fix: / chore:

- 一個 PR < 300 行，超過要拆

...

# 🚫 禁止事項

- 不要動 src/legacy/ 底下任何檔案

- 不要直接改 .env、不要把 token hardcode

...

💡 每個專案的 CLAUDE.md 只要寫「你最常需要重講的事」就夠了，不必塞滿

# 一句話心法

把團隊知識「永久灌進 AI」，而不是每次對話重講一次
