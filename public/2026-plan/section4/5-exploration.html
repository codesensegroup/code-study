Race condition / 記憶體洩漏

需要 runtime trace、profiler、heap snapshot — 靜態讀檔案看不出來。

💡 該做：你把 profiler / log 貼給它分析

👁️

純視覺 / UX bug

「按鈕排版怪怪的」「動畫卡卡」— 需要肉眼或瀏覽器互動。

💡 該做：截圖貼給它 + 配 Playwright MCP

🎭

動態 / 反射程式碼

PHP magic method、Python getattr、JS eval — call graph 是 runtime 才知道。

💡 該做：你補上「執行範例」當線索

☁️

只發生在 production 的 bug

流量、DB 真實資料、第三方 API 才會觸發 — 本機 repo 看不出來。

💡 該做：把 production log / 監控數據貼進來
